# 塔防战争 · 十二款地砖资源

共十二组：草地六组、陆地六组。每组包含一个可直接引用的地砖 Prefab、一份材质、一张 4096×4096 RGBA 贴图，以及斜视和正交顶视预览。另附两份拼接示例 Prefab。

## 导入与替换

1. 解压资源包，在 Unity 中双击其中的 `.unitypackage`，或使用 **Assets → Import Package → Custom Package**，完整导入 `Assets/TerrainTileStyles`。
2. 草地资源位于 `Prefabs/Grass`，陆地资源位于 `Prefabs/Land`。贴图、材质、网格和独立着色器均随包提供。
3. 当前工程已安装同一批资源，可直接使用，不必再次导入。
4. 在地形的 `TerrainTileGridGenerator` 中增加 `Tile Variants` 条目，把对应 Prefab 指定为 `Tile Object`，把 `Previews/*_Top.png` 指定为 `Editor Preview`。保持原条目的索引与顺序，新增样式追加在末尾。
5. 网格继续使用原有 `Row Spacing / Column Spacing = 0.85`、`Tile Euler Angles = (90, 0, 0)`、`Tile Scale = (1, 1, 1)`。生成器覆盖根节点位置、旋转和比例，新增 Prefab 的网格与原模型一致。
6. 手工摆放时，新 Prefab 默认已保存 X=90°，根位置为零；直接按 0.85 的格距复制即可。草地和陆地保留各自原模型的厚度，按原模型方式混合摆放。
7. 这批资源只提供视觉样式。可行走区域、基地、起点、终点等标签和 Collider 规则继续由地形条目配置，不应把装饰变体直接当作新的基地或路径标记。

`Demo/TwelveStyles.prefab` 展示十二种样式；`Demo/RegionExample.prefab` 展示分区草地与中间陆地通道。示例仅包含模型，可拖入场景查看；十二款总览示例根节点默认隐藏，勾选 Active 即可显示。

## 与原资源的对齐

| 项目 | 保持方式 |
|---|---|
| 草地网格 | 原 `Assets/Model/TerrainModel/001.glb` 网格的完整副本；2222 顶点、2349 三角形 |
| 陆地网格 | 原 `Assets/Model/TerrainModel/002.prefab` 所引用网格的完整副本；4402 顶点、4000 三角形 |
| 尺寸与厚度 | 每类保留对应原模型的顶点和 Bounds，不统一拉伸两类模型 |
| UV、法线、拓扑 | 保留原数据，草地石块和陆地铺砖的既有几何细节继续保留 |
| 渲染精度 | 原生 4096×4096；8 位 RGBA、无压缩；保留 13 级 mipmap、双线性、Aniso=1、Repeat 及源颜色空间设置 |
| 材质参数 | 复制原材质的颜色、数值、UV 变换、剔除、混合、深度写入、Render Queue、关键词等，仅替换颜色贴图 |
| 着色器 | 原 `glTF/Unlit` 的独立代码副本，命名为 `TowerDefense/Tiles/SourceUnlit`，避免同名冲突；计算逻辑和属性定义保持一致 |
| Renderer 与 Collider | 保留来源的渲染设置及 Collider 数量 |

源嵌入纹理的 Unity 格式显示为 ARGB32，外置 PNG 导入采用 RGBA32；这是通道存储顺序的差异，两者均保留无压缩 8 位 RGBA 的渲染精度。细草、落叶、裂隙与砂砾的明暗烘焙在颜色贴图中，不添加法线贴图、额外几何或动态效果，符合原无光照材质。

六组草地共享一个网格，六组陆地共享另一个网格。4K 无压缩纹理与原资源精度一致；分区使用时按关卡选择所需材质。拼接时可以换用不同变体，也可手工以 Y 轴 90° 整倍数旋转整个地砖，减少重复感。

## 使用环境

按当前项目的 Unity 6000.3.26f1、Built-in Render Pipeline 制作。资源包内提供完整网格、材质、贴图和着色器依赖，使用时不需要导入原 GLB，也不需要地砖专用运行脚本。URP/HDRP 项目需要另行适配对应管线材质。

地砖基于当前工程原模型制作；独立着色器及 include 文件保留 glTFast / Unity 的许可标注，许可文本位于 `Shaders/LICENSE.md`。

验证记录随资源包提供。PICO 设备上的实际帧耗、纹理驻留和双目显示效果仍以实机为准。
